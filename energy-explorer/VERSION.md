# Version 0.1.0

Saved: October 7, 2026

Initial desktop release of Ontario Energy Explorer.

- React and TypeScript UI with MapLibre and 520 Ontario census FSA boundaries.
- Temperature scenarios from −40 to 35 °C, weekday/weekend selection, and looping hourly intervals.
- Light, Dark, and time-reactive Daylight themes.
- FSA search, hover inspection, persistent selection, and fixed consumption legend.
- FastAPI prediction API and replaceable batch model provider.
- Explicitly labelled synthetic demo predictions, pending trained-model integration.
- Setup documentation, API contract, and verification notes.

Validation: production build, four backend contract tests, 520-FSA live API join check, and desktop browser verification passed.
